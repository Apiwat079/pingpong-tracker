# Ping-Pong Tracker

เว็บติดตามลูกปิงปองจากกล้องด้วย ONNX Runtime และ WebGPU มีแกลเลอรีสำหรับภาพที่ผู้ใช้เลือกบันทึก และคาลิเบรตพื้นโต๊ะโดยแตะมุมเองหรือให้โมเดลเสนอ 4 มุมก่อนยืนยัน

โหมดประมวลผลบนอุปกรณ์ใช้ AI ของเบราว์เซอร์ ส่วนปุ่ม **จับโต๊ะอัตโนมัติ** ส่งภาพนิ่งหนึ่งเฟรมไปให้คอนเทนเนอร์ตรวจโดยไม่บันทึกภาพนั้นลงแกลเลอรี

## รันด้วย Docker

นำไฟล์ต่อไปนี้จากแพ็ก deploy ที่ได้รับสิทธิ์มาวางข้าง `Dockerfile` (repo ไม่เก็บน้ำหนักโมเดล):

- `best_960_fp32.onnx`
- `best_dyn_fp16.onnx`
- `best_dyn_fp32.onnx`
- `table_seg_640.onnx`

นำ `static/ort/` จากแพ็กเดียวกันมา หรือดาวน์โหลด runtime รุ่นที่กำหนดและตรวจ SHA-256 ก่อนใช้:

```sh
python fetch_runtime.py
docker compose up -d --build
curl -f http://127.0.0.1:8080/health
```

เว็บรันบน `127.0.0.1:8080` ตาม Compose ถ้าเปิดจากอุปกรณ์อื่นให้ใช้ HTTPS ผ่าน reverse proxy และกำหนดสิทธิ์เข้าถึงตามสภาพแวดล้อม ใช้หนึ่ง worker / หนึ่ง instance สำหรับคิวเดิมที่เก็บในหน่วยความจำ

รูปที่บันทึกอยู่ใน Docker volume ที่ `/data/captures` และไม่อยู่ใน Git อย่าใช้ `docker compose down -v` ถ้าต้องการเก็บรูปต่อ

## ตรวจการทำงาน

เมื่อวางไฟล์โมเดลและ runtime แล้ว ให้รัน `python smoke_test.py` และ `python table_test.py` ใน Linux environment ที่ลง `requirements.txt` ทั้งสองทดสอบใช้ข้อมูลชั่วคราวแยกจากแกลเลอรีจริง
